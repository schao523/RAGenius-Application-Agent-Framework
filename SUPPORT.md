# Support

Use GitHub Issues for reproducible defects and feature proposals. Include the
revision, operating system, subsystem, sanitized logs, expected behavior, and
actual behavior.

Do not post secrets, `.env` contents, email addresses, authentication links,
cookies, private artifacts, or provider responses containing personal data.
Use the private process in `SECURITY.md` for vulnerabilities.

The project is community-maintained and does not currently provide guaranteed
response times or commercial support.
