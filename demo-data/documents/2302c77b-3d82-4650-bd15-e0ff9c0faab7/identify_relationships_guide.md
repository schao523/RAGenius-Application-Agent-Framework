# 📘 External Resource: 認清關係觀察的項目 (Identify Relationships Guide)

## 📖 Resource Purpose

This resource defines the **16 observation items** for the *第二步驟：認清關係 (Identify Relationships)* phase of the Inductive Bible Study method.  

It enables the **Bible Teacher GPT** to analyze connections within a passage — such as cause and effect, contrast, structure, or flow — and to generate **contextualized guiding questions** to help users discern the relational logic of the text.

---

## 🔍 認清關係觀察的項目 (16項)

1. **上文下理 (Context)** — 經文前後文的思路與連貫性。  
2. **高潮點 (Climax)** — 整段經文的重心或轉折處。  
3. **總括性語句 (Summary Statement)** — 概括整段經文核心思想的語句。  
4. **映襯 (Contrast)** — 兩個相反的觀念或事件之間的對比關係。  
5. **比對 (Comparison)** — 類似事物或觀念的比較，用於說明相似之處。  
6. **重複詞句 (Repetition)** — 反覆出現的字詞或觀念，顯示作者的強調。  
7. **氣氛 (Atmosphere)** — 經文情感與語氣的變化，如平靜、緊張、喜樂、哀愁等。  
8. **語法結構 (Grammatical Structure)** — 句子的語法安排，包括主詞、動詞、語態與語氣等。  
9. **主要連接詞 (Significant Connective)** — 連接語句邏輯的詞語（如「因為」、「所以」、「但是」等）。  
10. **離題的插段 (Digression)** — 與主題略有偏離但含重要思想的插段。  
11. **遞進的觀念 (Progression of Ideas)** — 思想由小至大、由淺入深的發展過程。  
12. **比較譯本 (Comparing Translations)** — 不同譯本間的文字差異揭示意義層次。  
13. **質的關係 (Qualitative Relationship)** — 在性質或本質層面的對比與相似。  
14. **量的關係 (Quantitative Relationship)** — 以數量、分量或程度比較兩事物。  
15. **地域上的關係 (Spatial Relationship)** — 地理或空間上的相互關聯與影響。  
16. **時間上或年代上的關係 (Chronological Relationship)** — 事件發生的時間順序與歷史關聯。

## 🧠 How the Teacher GPT Uses This Resource

When a user studies a passage, the Teacher GPT should:

1. **Identify Contextual Relationships**  
   
   - 根據經文結構與內容，從上表中挑選適用的關係項目。

2. **Generate Reflective Questions**  
   
   - 對每個選定項目提出問題，如：  
     - 「這段經文的高潮點在哪裡？為什麼重要？」  
     - 「哪些詞語或句子形成對比或重複？」  
     - 「上文與下文如何彼此連接？」  
     - 「不同譯本是否揭示了新的關係或意義？」

3. **Guide Interaction Flow**  
   
   - 當使用者回答後：  
     - 若回答不完整 → 提供提示或補充問題。  
     - 若回答完整 → 詢問是否繼續探索其他關係項目或進入下一步（分析結構）。
